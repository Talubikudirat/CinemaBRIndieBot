# Cinema BR Indie Bot 🎬

Bot do Telegram para cinema independente brasileiro. Festival dates, submission deadlines & indie film news.

## Features
- 📅 Daily festival updates
- 📰 Latest cinema news
- 🏆 Awards and competition results
- 📝 Submission deadlines
- 📖 Telegraph articles with full details

## Commands
- `/start` - Welcome message
- `/festivais` - Active festivals
- `/noticias` - Latest news
- `/premiados` - Recent awards
- `/hoje` - Daily summary
- `/submissoes` - Open submissions

## Deploy on Railway
1. Fork this repo
2. Create new Railway project
3. Add `TELEGRAM_BOT_TOKEN` as environment variable
4. Deploy!

## Tech Stack
- Python 3.11
- python-telegram-bot
- BeautifulSoup4
- Telegraph API
- Web scraping (no API keys required)
